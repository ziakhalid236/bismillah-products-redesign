# Bismillah Textile — Website Redesign

A responsive, multi-page static website concept with an original cream, maroon and muted-gold visual system and original SVG illustrations.

## Pages
- `index.html` — Home
- `products.html` — Product catalogue with filters and detail modals
- `manufacturing.html` — Manufacturing departments and units
- `quality.html` — Quality approach
- `partners.html` — Products and partnerships
- `contact.html` — Contact page with an email-app enquiry form

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Important content note
This is a design-ready concept. Exact factory contact numbers, email addresses, certifications, customer names/logos, production capacity and claims about on-site departments must be checked against Bismillah Textile's official company information before publishing. Generic department pages describe representative textile-manufacturing functions and do not claim that each unit is confirmed to exist at the factory.

All artwork in `assets/` is custom-created SVG illustration and is not presented as documentary photography of the actual factory.
